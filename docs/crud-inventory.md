# Optical CRM operation inventory

Audit date: 23 October 2026 (Asia/Kolkata). This describes the current working tree, including changes that existed before this audit. No unsupported operations were added.

All paths below are relative to `/api`. Business routes use `requireAdmin`, which authenticates both active ADMIN and USER accounts: USER is deliberately allowed daily CRM workflows. Settings management requires ADMIN. Services obtain the single supported shop using `shopService.getShopId()` / `DEMO_SHOP`; accounts are global to this single-shop application, not tenant memberships. A second synthetic shop is used to test object isolation.

`resolveCatalogSelection` validates new catalog IDs within the purchase transaction and preserves existing inactive product snapshots. `recordSchema` is shared by customer creation, compatible customer updates, historical purchase edits, and new purchases. Prescription mapping preserves omitted fields; explicit null clears values.

## Persistent features without independent CRUD

- Notes: `Customer.notes` is editable in Personal Details. No current note-version model, controller, service or UI endpoint exists. Permanent deletion conservatively checks optional legacy `CustomerNoteVersion` tables.
- Inventory/supplier imports: no stock, supplier, movement or import models/routes/UI in the canonical checkout. Catalog management is supported; stock quantity and supplier imports are not.
- Shop: Prisma seed and admin tooling provision the single shop. No shop-management UI or multi-shop account assignment exists.
- PIN configuration: maintenance command `server/scripts/admin/setDeletionPin.ts`; no public PIN creation/reset UI. The audit configures its own synthetic administrator only.
- Order history: initial/status transitions append history. No independent history edit/delete UI exists.
- PasswordResetToken, AdminSession, AccountRateLimit: internal lifecycle persistence; no general-purpose CRUD UI.
- PDF/receipt/WhatsApp exports are document/share actions, not database writes. They are outside persistence CRUD.
- Deployment: repository README documents build/static hosting/API proxy and manual Prisma migration steps. No checked-in deployment provider or CI workflow was found.

See [the audit report](crud-audit-report.md) for executed evidence, fixes, limits and current results. An inventory entry describes support, not proof that its UI was tested.
